# 详细设计

## 前端

前端所有页面请求需要带上token,如果后端鉴权失败，则跳转到引流页面
- 引流页面
- 文件列表页面
- 404页面



已文件夹的形式展示文件列表，每一次请求都需要带上token

浏览器路径对于到文件夹路径

下载文件时使用JWT生成一个下载url，在短时见内可以用于下载某个文件


## 接口

1. 鉴定token（鉴定时间，身份）
2. 获取指定文件夹目录下的文件列表
3. 获取指定文件的下载地址
4. 下载文件


## 后端


1. 中间间对于下载文件和获取文件列表的请求进行sleep
2. 对小文件进行更小的限流

每一个小时更新一次文件资源列表

token计算逻辑：

JWT(服务器密钥+{身份,日期})
